## Implemented

- `./build_apk.sh` now defaults to `--export-release` and `build/arena_dash_release.apk`. Explicit `debug` remains available. Missing credentials stop publication; no replacement key or debug fallback is created.
- Production credentials use Godot's supported `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER`, and `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD`. Passwords stay in the build environment and are not printed by the script. Private keys are ignored/excluded from exports.
- The primary package remains `com.example.arenadash`; version code is 2/name 1.1. Exact Godot 4.7.2 debug/release template links remain. Release export disables the existing debug-only diagnostics and QA automation.
- Validation before atomic publication checks signing certificate against the selected production alias, decoded manifest, release debug/test flags, package/version, standalone layout, arm64-v8a, native/DEX identity against the exact export template, ZIP integrity, alignment, and launcher density/adaptive resources. Reports are written in `qa/build-verification/`.
- The updated root `icon.svg` (2026-10-12 09:05; SHA-256 `776d40e5fc13f4ed5dcce7c2f3a1ea1c1e29f4fefabfa39f6d97e6538887ac2e`) is newer than the October 10 logo copies. The loading screen also uses this vector, replacing its stale reference to an old logo PNG that is no longer present. Existing artwork is separated into adaptive radar/background and aircraft/foreground layers, preserving its paths, gradients, colors and filters. Sharp/librsvg renders transparent filters correctly. No new logo is drawn. Foreground visible radius is 130.58 of 132 pixels; background is opaque to the edges. Legacy sizes 48/72/96/144/192 and adaptive 432 layers are regenerated on every successful build.
- Packaged xxxhdpi legacy, foreground and background pixels exactly match regenerated sources. See `qa/advanced-release/icon-comparison.json`.
- Seven levels are appended after the original eight: Lava Frontier (9), Ice Crown (10), Desert Siege (11), Toxic Refinery (12), Storm Reach (13), Crystal Nexus (14), Dark Void (15). Separate advanced desert/toxic IDs preserve the original worlds and save keys.
- All seven corresponding future-update map backgrounds, tile textures, atmosphere overlays and planet artworks are reused. Tiles repeat at their original aspect instead of being stretched. Textures are shared across chunks; no new particle systems are added. All 148 supplied future-update SVG/PNG assets are byte-identical to the checkpoint.
- Advanced scouts/interceptors/fighters/bombers/plasma drones/destroyers/battleships reuse the existing pursuit, flank, charge, orbit and guardian AI, collisions, invulnerability and warning intervals. Boss volley patterns and escort formations vary by world. Enemy population is capped at 30; hostile projectile cap remains 64.
- Levels 9–15 gradually increase movement 182–218, initial spawn interval 0.945–0.675 seconds, attack interval 2.42–1.88 seconds, projectile speed 296–332, regular armor 2–6, guardian health 36–48, and kill objective 64–100. Existing levels' tuning remains unchanged.
- Three-star prerequisite chains, rating boundaries, equipment ownership and save/economy implementation are preserved. First three-star rewards increase from 540 to 600 coins; repeat awards exclude the existing 250-coin one-time bonus. Repeated completion of one attempt cannot duplicate rewards.
- Selection uses two pages of the existing constellation route, retaining readable planets, stars and briefing. Names/challenges/difficulty are localized in English/Indonesian. The home summary derives the aircraft/world counts from the actual catalogs and updates with language changes.

## Verification and limits

All 29 headless scene suites passed, including the full 15-world stability stress (183 seconds), and five existing Python tests passed. The test timeout was raised from 180 to 240 seconds for the expanded campaign. Early failures from eight-world assertions and QA harness crowding were corrected and retested; raw initial and final results are retained. The detailed machine results, manifest/signature reports, device Logcat and screenshots are under `qa/advanced-release/`. The separate existing `com.example.arenadash.review` QA preset uses opt-in debug automation and isolated `advanced_campaign_save.cfg`. Twelve seconds of actual rendered gameplay ran on every new world; controlled QA objectives then exercised actual guardian defeat, mission completion, rewards, duplicate-award guards and save reload. This is a functional harness, not a complete human playthrough or balance certification.

On the Redmi Note 8, all seven worlds passed with zero harness failures. Snapshot gameplay FPS was 41–43, GPU time approximately 16–18 ms, with scene-load pauses up to approximately 1.75 seconds. No orphan nodes were recorded. These measurements do not establish sustained 60 FPS. Main-player saves were not used for QA. The existing main save remained byte-identical before/after testing (SHA-256 `595eb10a3cc8426228c925e395a40a325ea5936a5cec872dbfde7f96d42cfe68`).

The latest development APK is validated and explicitly named `build/arena_dash_debug.apk`. It is not a production release. No `arena_dash_release.apk` has been published because production credentials are still unavailable to this build environment. The user confirms an existing production key, but its path/alias and secure password setup remain required. The script's default invocation was actually attempted and stopped with the missing-credentials message.

The main game was absent in the initial live check, then reappeared with version 1/code 1 and the established debug certificate during testing. Its save was backed up privately in `.maintenance/recovery/phone-save-before-release-20261012.cfg`; the installed APK was also backed up. A production key differing from that debug certificate cannot normally replace this installed package. No uninstall, data clear, package-ID change, signing-key generation, or security setting change was performed.

A production release's ADB install, normal installer acceptance, release-mode launch and launcher appearance remain unverified until the signing credentials and update compatibility can be checked. Historical Play Protect SAFE approval of a previous debug APK does not certify this release or every future artifact. See `DIRECT_INSTALL_FIX.md` for that previous artifact's evidence.
