# Future Updates Asset Collection

This directory contains a complete collection of high-quality, production-ready vector SVG assets created for future game expansions. All assets are designed based on the provided visual references, following arcade sci-fi art standards with vibrant gradients, specular highlights, and cohesive proportions.

> [!NOTE]
> **Isolation Guarantee**: None of these assets have been injected or integrated into the current live game codebase or scenes. They reside strictly within `assets/future_updates/` ready for seamless modular adoption in future update milestones.

---

## 1. Directory Structure

```text
assets/future_updates/
├── aircraft/                  # 5 Starfighter & UFO ships
├── maps/                      # 2 Progression map overviews + 8 Celestial planet levels

└── ui/                        # 20 Arcade UI elements (Logos, Modals, Buttons, HUD, Badges)
```

## 3. Future Integration Roadmap

When scheduling the future update, these assets can be connected into the project as follows:

1. **Fleet Expansion**:
   Add entries into `scripts/hangar.gd` and `scripts/game.gd` mapping `player_saucer.svg`, `player_rocket.svg`, `player_wedge.svg`, `player_speeder.svg`, and `player_booster.svg` with speed, handling, and shield multipliers.
2. **Campaign Overhaul**:
   Use `map_galaxy_spiral.svg` or `map_starfield_horizon.svg` as interactive stage selectors, instantiating the 8 `planet_*.svg` nodes with `badge_star_active.svg` / `badge_star_inactive.svg` ratings.
3. **In-Game Obstacles & Loot**:
   Swap/expand obstacle pool with `obstacle_space_rock_small.svg`, `obstacle_space_rock_large.svg`, and `obstacle_asteroid_platform.svg`. Replace coins and gems with `pickup_gold_coin.svg`, `pickup_crystal_gem.svg`, and spawn `pickup_loot_chest.svg` at boss/checkpoint milestones.
4. **UI Reskin**:
   Load `modal_reward_dialog.svg`, `modal_level_complete.svg`, and the full action button kit into UI scenes for a consistent arcade mobile interface.
